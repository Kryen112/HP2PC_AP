## Vendor card sales (M8)

- [x] **Vendor card sales as AP recovery path** — vendors keep selling bronze/silver cards, but the spawned card is rewritten on the fly so the sale fires the AP CHECK for the original card location. Three phases:
    - **Phase A (filter, done):** `APCardWatcher.ClearVendorOwnershipForLocation(id)` sets `siCard.SetCardOwner(id, CardOwner_None)` for any AP-checked location, so vanilla `GetFirstVendorCardId` skips them. Called from `APCardMarker.Touch` on every pickup, from the watcher's fallback CHECK path, and from `SweepVendorAssignments` (run in `Snapshot` after `Bind`) which retroactively undoes vanilla `AssignVendorCards` (re-runs every save / level transition / `AssignAllSilverToVendors` at GState 180). Without this, vanilla would re-stamp `CardOwner_Vendor` on every AP-checked card on every level entry; the player would waste beans on duplicate CHECKs that AP dedupes.
    - **Phase B (replacement, done):** `APCardWatcher.ReplaceVendorSpawnedCards` (called from Timer) scans loose `WizardCardIcon` actors and replaces any non-marker class with the corresponding `APCardMarker_<class>` at the same Location, marked as loose. This catches the vanilla `WCXxx` spawned by `Characters.MakePurchase` (`Characters.uc:646`) and turns it into a marker before pickup, so the marker's clean Touch path fires CHECK without going through vanilla `SetCardOwner(Harry)` (which would briefly show the card in the album before the watcher's revert kicks in). Already-AP-checked locations get their vanilla wci destroyed with no replacement (mirrors `ReplaceCardChests`'s loose-icon path). Race window: 0-0.25s between vendor spawn and replacement; vendor cards arc-bounce for ~1-2s before they're pickup-able, so the player almost never beats the swap. If they do, the watcher's `IsHarryOwned` polling path catches it as a fallback (CHECK fires, with album flicker).
    - **Phase C (assignment, done):** vanilla `AssignVendorCards` reads `slotClass.Default.Id` + `slotClass.Default.bVendorsCanSell`, both wrong on our markers (`Default.Id=200` sentinel for bean-swap immunity; `bVendorsCanSell=False` inherited from `WizardCardIcon` base). `gen_apworld.py` now bakes `bVendorsCanSell` + `strVendorOwnedAfterGState` + a `MarkerTier` field ("Bronze"/"Silver"/"Gold") into each generated marker subclass — values harvested from each `WCXxx.uc` vanilla default in `HP2UScriptDecompile/HGame/Classes/WizardCards/` (stable across game versions, frozen 2026-05-12 in `CARD_VENDOR_META`). `APCardWatcher.AssignMarkersToVendors()` mirrors vanilla's pass over chest `EjectedObjects[]` / cauldron `EjectedObjects[]` / loose `APCardMarker` actors, but uses `marker.CardLocationId` (real id, 1-101) and routes to the right si via `MarkerTier`. Skips already-AP-checked locations and gates by `iGameState >= int(Right(strVendorOwnedAfterGState, 3))`. Called from `Snapshot` (initial / save load / level transition) and from the iGameState-transition branch of `Timer` so cards become vendor-available the moment their game-state gate opens. 59 of 101 cards are vendor-eligible in vanilla; gold cards are non-sellable (set rewards). Combined effect of Phases A+B+C: missed cards from un-replayable levels (Goyle, Slytherin, etc.) become beans-priced AP-recovery purchases at any vendor, with the spawned card rewritten on the fly to fire the original location's AP CHECK rather than granting the vanilla card.

- [x] **Skurge bookcase** — `APGameInfo.BlockSkurgeClassroomIfMissing` mirrors the Ricta pattern: spawns a `BookcaseGlassDoors` at the Flitwick Skurge intro cutscene's Location + `SkurgeBlockerOffset` when `APGrantedSpell[5]==0`, removed via `RemoveSkurgeBlocker` (direct ref + `APSkurgeBlocker`-tag scan fallback) when AP grants Skurge. - [x] **Diffindo bookcase** — `APGameInfo.BlockDiffindoClassroomIfMissing` blocks the wide Sprout's-classroom entrance with a row of 3 bookcases (one per `DiffindoBlockerOffsets[i]` slot).
